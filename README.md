# Crystal TD

A small rhythm tower defense. Enemies march along a fixed path on the beat. You place towers, slot crystals into them, and trigger their attacks by pressing the matching element key in time with the music. Perfect timing deals critical damage.

Made for [Mini Jam 220: Crystal](https://itch.io/jam/mini-jam-220-crystal/rate/5062193) (theme: *Crystal*, limitation: *Timing is everything*).

## Crystals

| Key | Crystal | Effect |
|---|---|---|
| Q | Nature | Damage and freeze |
| W | Fire | Area damage |
| E | Lightning | Chains between enemies |

## Tech

- Unity 6000.3.8f1
- Beat timing based on `AudioSettings.dspTime`

Open the folder in Unity Hub with the matching editor version.
